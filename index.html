Sambungkan ke Google Spreadsheet

Masukkan URL Web App dari **Google Apps Script** agar setiap data formulir yang diisi oleh peserta otomatis terkirim langsung ke Spreadsheet milik Anda secara *real-time*.

Cara Membuat Kode Google Apps Script (3 Menit):

  1. Buka Google Sheets baru.
  2. Klik menu Ekstensi → Apps Script.
  3. Hapus semua kode lama, lalu tempel (paste) kode di bawah ini:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = e.parameter;
  
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tanggal/Waktu", "Nama Siswa", "Kelas", "Jenis Kelamin", "Kategori Lomba", "Detail Lomba", "No WhatsApp Wali", "Catatan"]);
  }
  
  sheet.appendRow([
    data.timestamp || new Date(),
    data.namaLengkap,
    data.kelas,
    data.jenisKelamin,
    data.kategoriLomba,
    data.subDetail,
    "'" + data.noWhatsapp,
    data.catatan
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({ "result": "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Klik Terapkan (Deploy) → Penerapan Baru (New Deployment).
  2. Pilih Jenis: Aplikasi Web (Web App).
  3. Pada *Siapa yang memiliki akses (Who has access)*, pilih **Siapa saja (Anyone)**.
  4. Klik **Terapkan (Deploy)**, berikan izin akses, lalu salin **URL Aplikasi Web** dan tempel pada kolom di atas!

Pendaftaran Berhasil!
